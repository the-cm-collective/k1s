# Roadmap Status

Status: canonical milestone index for the AI Max+ 395 fabric path.

Use this page to track the control-plane HA phases (`H*`) as the foundation for true HA core, the fabric substrate phases (`F*`) as the AMD-first capability track, and the deployment milestones (`D*`) as the secondary provider-exposure track. Do not treat later milestones as active until their listed dependencies have a clear exit decision.
